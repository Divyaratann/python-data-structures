# 🐍 Python Data Structures – Tuples, Lists, Sets & Dictionaries

Welcome to my **Python Data Structures** repository! This repository contains Python programs and practical examples to understand fundamental data structures and functions in Python.

The purpose of this repository is to practise Python programming concepts and learn how to store, access, and manipulate data using built-in data structures.

## 📚 Topics Covered

### 1. 📦 Tuples (`tuples.py`)
- Creating tuples
- Accessing tuple elements
- Tuple indexing and slicing
- Tuple properties and operations
- Understanding immutable data structures

### 2. 📋 Lists (`list.py`)
- Creating and accessing lists
- List indexing and slicing
- Adding and removing elements
- Updating list elements
- Common list methods

### 3. 🔢 Sets (`set.py`)
- Creating sets
- Adding and removing elements
- Removing duplicate values
- Union, intersection, and difference
- Understanding unique elements

### 4. 📖 Dictionaries (`dictionary.py`)
- Creating dictionaries using key-value pairs
- Accessing dictionary values
- Adding and updating entries
- Removing key-value pairs
- Using common dictionary methods

### 5. ⚙️ Functions (`function.py`)
- Defining functions using `def`
- Calling functions
- Passing arguments and parameters
- Returning values
- Reusing code through functions

## ⚙️ Getting Started

### Prerequisites

Install Python from the official website:

https://www.python.org/downloads/

### Clone the Repository

```bash
git clone https://github.com/Divyaratann/tuples-in-python.git
```

### Navigate to the Project Folder

```bash
cd tuples-in-python
```

### Run the Programs

Run any Python file using the following commands:

```bash
python tuples.py
python list.py
python set.py
python dictionary.py
python function.py
```

## 💻 Example Code

### Tuple Example

```python
numbers = (10, 20, 30, 40, 50)

print(numbers)
print(numbers[0])
print(numbers[1:4])
```

### List Example

```python
fruits = ["Apple", "Banana", "Mango"]

fruits.append("Orange")
print(fruits)
```

### Set Example

```python
numbers = {1, 2, 3, 3, 4, 5}

print(numbers)
```

### Dictionary Example

```python
student = {
    "name": "Divyaratann",
    "course": "B.Tech CSE"
}

print(student["name"])
```

### Function Example

```python
def greet(name):
    return "Hello, " + name

print(greet("Python"))
```
